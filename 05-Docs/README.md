# 文档归档

架构说明、接口约定、数据规范、开发记录和验收文档的归档目录。

## 文档清单

| 文档 | 用途 | 位置 |
|------|------|------|
| 需求说明 | 第一版 MVP 需求清单 | `AI教师系统_第一版MVP需求说明.md`（仓库根目录） |
| 环境搭建与运行时配置 | 运行时初始化（PostgreSQL / JWT / DLL）与 .env 配置、部署步骤 | `05-Docs/环境搭建与运行时配置.md` |
| 开发计划与进度 | 开发计划（Phase 0–9）、里程碑记录、当前状态摘要 | `Dev_Plan.md`（仓库根目录） |
| 调试记录 | 开发问题、根因与解决方案（P 编号，按时间倒序） | `Dev_Problem.md`（仓库根目录） |
| 技能与课程引擎 | 学科/风格/课程三层结构、技能编写约定 | `01-Skills/README.md` |
| 数据资产 | 数据目录约定、书籍三层镜像、入库策略 | `02-DATA/README.md` |
| 后端说明 | 后端接口、TTS 引擎策略、服务清单 | `03-Backend/README.md` |
| 前端说明 | 页面、架构、流式协议、语音/音色 | `04-Frontend/README.md` |
| 工具链 | OCR 工具、公式蒸馏管道、本地 TTS | `06-Tools/README.md`（各工具目录内还有 README） |

## 文档约定

- **README 分级**：根目录 README 只做项目总览与导航；各目录 README 介绍各自文件夹的内容与约定；调试记录统一收敛到 `Dev_Problem.md`。
- 新增文档按主题命名；核心约定（学科/风格/课程三层结构、蒸馏判据、进度存储位置）同时在其所属目录的 README 中维护。
- 每个功能/修复完成后，同步更新对应 README 与 Dev_Plan 的进度记录，重大排查过程记入 Dev_Problem.md。
