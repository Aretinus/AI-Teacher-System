# 例题：面积与积分

## 题目

曲线 $y = x^2$ 与直线 $y = 0$、$x = 0$、$x = 2$ 围成的区域，面积是多少？

## 解题思路

**图形直觉**：$[0, 2]$ 区间内曲线下方、$x$ 轴上方的区域。

**面积 = 定积分**：

$$\text{Area} = \int_0^2 x^2\,dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} - 0 = \frac{8}{3}$$

**验证**（基本定理三步）：

1. 找反导数：$F(x) = \frac{x^3}{3}$（因为 $F'(x) = x^2$）
2. 代入上端点：$F(2) = \frac{8}{3}$
3. 减去下端点：$F(2) - F(0) = \frac{8}{3}$

## 教学要点

- 强调"面积问题 → 定积分"的建模思路。
- 复习基本定理：找反导数 → 端点代入 → 相减。
- 面积单位：若坐标是米，面积单位是平方米。
