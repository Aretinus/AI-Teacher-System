# 例题：速度与位移（导数即变化率）

## 题目

一物体沿直线运动，位移函数 $s(t) = t^2 - 3t + 2$（米，$t$ 秒）。

1. 求 $t = 3$ 秒时的瞬时速度。
2. 何时速度为 0？此时物体在做什么？
3. 求 $t = 1$ 到 $t = 3$ 的平均速度。

## 解题思路

**第 1 问**：瞬时速度 = 位移的导数。

$$v(t) = s'(t) = 2t - 3 \implies v(3) = 2 \cdot 3 - 3 = 3 \ \text{m/s}$$

**第 2 问**：$v(t) = 0 \implies 2t - 3 = 0 \implies t = 1.5$ 秒。

- 速度为 0 意味着此刻物体**瞬时静止**——方向正要翻转（先向左后向右）。

**第 3 问**：平均速度 = 总位移 ÷ 总时间。

$$s(3) - s(1) = (9 - 9 + 2) - (1 - 3 + 2) = 2 - 0 = 2 \ \text{m}$$

$$\bar{v} = \frac{2}{2} = 1 \ \text{m/s}$$

## 教学要点

- 第 1 问复习"瞬时变化率 = 导数"。
- 第 2 问建立"导数为零 ↔ 瞬间静止/极值点"的直觉。
- 第 3 问区分平均 vs 瞬时：平均速度是割线斜率，瞬时速度是切线斜率。
