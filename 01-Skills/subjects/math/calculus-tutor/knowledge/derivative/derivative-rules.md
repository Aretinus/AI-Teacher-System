# 基本求导法则与链式法则

知识点 id：`derivative-rules`

## 核心直觉

有了导数定义后，每求一个导数都算极限太慢。求导法则是"提速工具"——它们是从定义推导出来的快捷规则，不是新概念。

## 基本法则

| 法则 | 公式 |
|---|---|
| 常数的导数 | $(c)' = 0$ |
| 幂函数 | $(x^n)' = n x^{n-1}$ |
| 常数倍 | $(c f(x))' = c f'(x)$ |
| 加法 | $(f + g)' = f' + g'$ |
| 减法 | $(f - g)' = f' - g'$ |
| 乘法 | $(fg)' = f'g + fg'$ |
| 除法 | $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$ |
| 链式法则 | $(f(g(x)))' = f'(g(x)) \cdot g'(x)$ |

## 链式法则的直觉

**链式法则 = 逐层微分，层层相乘。**

**嵌套情境**：俄罗斯套娃——外套改变速率 × 内套改变速率。

**例**：$y = (3x+1)^5$

- 外层：$u^5$ 对 $u$ 求导 → $5u^4$
- 内层：$u = 3x+1$ 对 $x$ 求导 → 3
- 结果：$y' = 5(3x+1)^4 \cdot 3 = 15(3x+1)^4$

**单位直觉**：速度是"层数/时间"，链式法则把嵌套层的速率乘起来得到总速率——外层速率 × 内层速率。

## 学生需要掌握的

1. 记住幂法则 $(x^n)' = nx^{n-1}$，包括负数指数与分数指数（$x^{-1}$、$x^{1/2}$）。
2. 链式法则的**乘法结构**：漏乘内层导数是头号错误。
3. 判断"乘"还是"复合"：$x \cdot \sin x$ 用乘法法则；$\sin(x^2)$ 用链式法则。

## 典型讲解例子

**例**：求 $f(x) = \sin(x^2)$ 的导数。

- 外层 $\sin u$，内层 $u = x^2$
- $f'(x) = \cos(x^2) \cdot 2x$

## 理解检查建议

- 问："求 $(2x+3)^4$ 的导数，并解释你用了哪两条法则。"
- 问："$\sin(x) \cdot x^2$ 与 $\sin(x^2)$ 的求导有什么区别？"
