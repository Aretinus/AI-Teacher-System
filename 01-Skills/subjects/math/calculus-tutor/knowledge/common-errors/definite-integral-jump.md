# 常见错误：定积分跳过找反导数

错误 id：`definite-integral-jump`

## 错误表现

学生写 $\int_1^2 x^2\,dx = \left[\frac{x^3}{3}\right]_1^2$ 时把 $\frac{x^3}{3}$ 直接当成"代入后求值"的表达式，不理解它是被积函数的**反导数**；或干脆直接代入端点运算：$\int_1^2 x^2\,dx \overset{错}{=} 2^2 - 1^2 = 3$。

## 为什么错

- 定积分的关键中间步骤：**先找到反导数 $F$**（满足 $F' = f$），再算 $F(b) - F(a)$。
- "代入端点"应用在 $F$ 上，而不是 $f$ 上。
- 跳过找反导数 → 结果错误且无法验证（正确 $\int_1^2 x^2\,dx = \frac{8}{3} - \frac{1}{3} = \frac{7}{3}$）。

## 正确认知

三步流程：

1. 找反导数：$F(x)$ 使 $F'(x) = f(x)$
2. 代入上端点：$F(b)$
3. 减去下端点：$F(b) - F(a)$

## 纠错话术

"定积分的值不是把函数本身在端点相减，而是：先把'面积累积函数'（反导数）找出来，再看它在两端点的差值。回忆一下，$\int x^2\,dx = \frac{x^3}{3} + C$，验证一下它的导数确实是 $x^2$，再代入端点。"

## 检测问题

- "$\int_0^2 3x^2\,dx$ 等于多少？写出完整三步。"
- "为什么 $\int_a^b f(x)\,dx$ 不能直接写成 $f(b) - f(a)$？"
