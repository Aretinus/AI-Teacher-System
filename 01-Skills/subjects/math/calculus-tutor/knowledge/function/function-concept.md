# 函数概念

知识点 id：`function-concept`

## 核心直觉

函数是"输入 → 输出"的规则：给一个输入，得到**唯一**的输出。

**日常情境**：饮料机。按"可乐"按钮（输入）→ 得到一杯可乐（输出）。同一按钮总是给同样的饮料，不会这次可乐下次橙汁。这就是函数的确定性。

**数学表达**：$f: x \mapsto f(x)$，自变量 $x$ 进入，因变量 $f(x)$ 出来。

## 关键要素

- **定义域**：允许的输入集合（如 $f(x) = \sqrt{x}$ 要求 $x \ge 0$）。
- **值域**：实际产生的输出集合。
- **图像**：把所有点 $(x, f(x))$ 画出来。垂线测试：任何竖线与图像至多交于一点，才是函数。
- **函数不是公式**：$f(x) = x^2$ 与"身高 → 体重"都是函数，一个用公式描述，一个用规则描述。

## 学生需要掌握的

1. 一个输入只能对应一个输出（垂线测试）。
2. 定义域 ≠ 值域。
3. 函数符号 $f(3)$ 表示"把 3 代入规则 f"。

## 典型讲解例子

**例**：$f(x) = x^2 + 1$，求 $f(2)$、$f(-1)$、$f(0)$。

- $f(2) = 5$，$f(-1) = 2$，$f(0) = 1$

## 理解检查建议

- 问："判断 $x = y^2$ 是否是 y 关于 x 的函数，用垂线测试解释。"
- 问："$f(x) = \frac{1}{x-2}$ 的定义域是什么？为什么？"
