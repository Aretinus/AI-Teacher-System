# 复合函数与反函数

知识点 id：`function-composite`

## 核心直觉

**复合 = 流水线**：先把输入送进第一台机器，再把输出送进第二台机器。

**日常情境**：洗衣服。先过洗衣机（去污），再过烘干机（去水）。"先洗后烘"是两道工序的流水线——$(烘 \circ 洗)(衣服)$。

**数学表达**：$(g \circ f)(x) = g(f(x))$。注意顺序：**先 f 后 g**，从右往左读。

**反函数 = 逆向工序**：把输出变回输入。$f^{-1}(f(x)) = x$。比如"烘干"的反过程是"淋湿"。

## 关键要素

- 复合顺序：$(g \circ f)(x)$ 先算 $f(x)$，再代入 $g$。
- 反函数存在条件：$f$ 必须一一对应（单调函数）。
- $f^{-1}(x)$ 图像：$f(x)$ 图像关于直线 $y=x$ 对称。

## 学生需要掌握的

1. 复合与乘法的区别：$(g \circ f)$ 是"先后执行"，不是 $g(x) \cdot f(x)$。
2. 反函数符号 $f^{-1}$ 是"逆"，不是"倒数"——$f^{-1}(x) \ne \frac{1}{f(x)}$。
3. 求反函数步骤：解 $y = f(x)$ 得 $x = f^{-1}(y)$，再交换变量名。

## 典型讲解例子

**例**：$f(x) = 2x+1$，$g(x) = x^2$。

- $(g \circ f)(x) = g(2x+1) = (2x+1)^2$
- $(f \circ g)(x) = f(x^2) = 2x^2 + 1$
- 两者不同：顺序很重要！

## 理解检查建议

- 问："$f(x) = 3x - 6$ 的反函数是什么？验证 $f^{-1}(f(2)) = 2$。"
- 问："为什么 $f(x) = x^2$（x 取全体实数）没有反函数？"
