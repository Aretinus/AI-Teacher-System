# 微积分基本定理

知识点 id：`integral-fundamental-theorem`

## 核心直觉

微积分基本定理把两个"看起不相关"的问题连成一座桥：**求导（变化率）与求面积（累积量）互为逆运算。**

**日常情境**：开车。车速表的积分（时间累积）= 路程；路程的导数 = 车速。同一件事的两种视角：累积与变化率互相还原。

**基本定理（第二部分）**：

$$\int_a^b f(x)\,dx = F(b) - F(a) \quad \text{其中 } F'(x) = f(x)$$

**含义**：想算曲线下面积，不用切无限条，只需要找反导数 $F$，代入端点相减。

## 关键要素

1. 求面积 → 找反导数 → 端点代入 → 相减。
2. 记号：$\left[ F(x) \right]_a^b = F(b) - F(a)$。
3. 基本定理是"积分难"的解法核心：几乎所有定积分都靠它，而非黎曼和。

## 学生需要掌握的

- $\int_1^2 x^2\,dx = \frac{8}{3} - \frac{1}{3} = \frac{7}{3}$
- 步骤：先找反导数（$\frac{x^3}{3}$），再代入端点相减
- 与不定积分的区别：定积分结果不含 $C$（相减抵消）

## 典型讲解例子

**例**：$\int_0^1 e^x\,dx$

- 反导数 $F(x) = e^x$
- $= e^1 - e^0 = e - 1$

## 理解检查建议

- 问："$\int_0^2 (2x)\,dx$，用基本定理计算，并解释每一步。"
- 问："为什么定积分结果里没有积分常数 $C$？"
