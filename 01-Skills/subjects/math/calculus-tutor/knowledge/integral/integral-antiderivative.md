# 反导数与不定积分

知识点 id：`integral-antiderivative`

## 核心直觉

**求导是"向前走"，积分是"往回找"。**

**日常情境**：看车速表开车。车速告诉你"现在多快"（导数视角）。但如果你想反推"刚才开了多远"——从速度找回距离，这就是积分（反导数视角）。

**数学表达**：若 $F'(x) = f(x)$，则 $F$ 是 $f$ 的一个反导数。

$$\int f(x)\,dx = F(x) + C$$

$C$ 是积分常数：因为常数的导数是 0，所以"往回找"只能找到相差一个常数的整个家族。

## 关键要素

1. $\int f(x)\,dx$ 是一**族函数**（加 $C$），不是单个函数。
2. 基本积分表与求导法则互为逆表：

| 求导 | 积分 |
|---|---|
| $(x^{n+1})' = (n+1)x^n$ | $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C \ (n \ne -1)$ |
| $(\sin x)' = \cos x$ | $\int \cos x\,dx = \sin x + C$ |
| $(\cos x)' = -\sin x$ | $\int \sin x\,dx = -\cos x + C$ |

3. 线性性：$\int (af + bg)\,dx = a\int f\,dx + b\int g\,dx$。

## 学生需要掌握的

- $\int x^2\,dx = \frac{x^3}{3} + C$（幂加一、除以新幂）。
- 验证方法：对结果求导，应得回被积函数。
- $C$ 为什么不能丢。

## 典型讲解例子

**例**：求 $\int (3x^2 + 2x)\,dx$。

- $= 3 \cdot \frac{x^3}{3} + 2 \cdot \frac{x^2}{2} + C = x^3 + x^2 + C$
- 验证：$(x^3 + x^2 + C)' = 3x^2 + 2x$ ✓

## 理解检查建议

- 问："求 $\int \frac{1}{x^2}\,dx$，并验证结果。"
- 问："为什么必须写 $+C$？举例说明两个反导数可以相差常数。"
