# Web UI 设计规范（清风蓝 · Clean Blue）

本规范约束 `04-Frontend` 全部页面的视觉与交互。设计令牌唯一定义在 `04-Frontend/src/styles/theme.css`（CSS 变量），**禁止在页面里硬编码中性色值**，一律使用 `var(--…)` 令牌。

## 1. 设计令牌

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg-page` | #f5f6f8 | #14161c | 页面背景 |
| `--bg-card` | #ffffff | #1e222b | 卡片/面板/头部 |
| `--bg-subtle` | #f3f4f6 | #262b36 | 次级填充（输入框、未激活 tab） |
| `--bg-accent-soft` | #f0f5ff | #1b2337 | 选中态/强调软底 |
| `--text-1` | #1f2937 | #e5e7eb | 主文字 |
| `--text-2` | #4b5563 | #c3c8d4 | 次文字 |
| `--text-3` | #9ca3af | #8b93a3 | 弱文字/占位 |
| `--border` | #e5e7eb | #2d3340 | 边框 |
| `--accent` | #4f8cff | 同 | 主色（链接、选中、主按钮） |

**品牌渐变**：`linear-gradient(135deg, #4f8cff, #7c3aed)`——仅用于品牌元素（Hero 横幅、新建对话主按钮、AI 头像、强调条），不得大面积铺底。

## 2. 字体层级

| 层级 | 字号 | 字重 | 色令牌 |
|---|---|---|---|
| Hero 标题 | 44rpx | 700 | 反白（横幅上） |
| 页面大标题 | 56rpx → 重设计后 40rpx | 700 | --text-1 |
| Section 标题 | 30rpx | 600 | --text-1（带强调条） |
| 正文/气泡 | 28rpx | 400 | --text-1 / 反白 |
| 辅助说明 | 24~26rpx | 400 | --text-3 |

## 3. 布局节奏

- 页面左右安全边距 **20rpx**；区块间距 **30rpx**；卡片内边距 **24~28rpx**。
- 卡片圆角 **20rpx**；气泡圆角 **18~20rpx** 且朝向侧收窄（用户气泡右上 4rpx、AI 气泡左上 4rpx）。
- 卡片阴影：`0 4rpx 16rpx rgba(17, 24, 39, 0.06)`；悬停/按压：`translateY(-2rpx)` + 阴影加深，过渡 `0.18s ease`。

## 4. 组件规范

- **Section 标题**：左侧渐变强调条（8×28rpx 圆角）+ 600 字重主色文字。
- **Hero 横幅**（主页首屏）：品牌渐变 + 反白文字 + 24rpx 圆角；深色下换深蓝紫渐变（#2b3a67 → #4c2b8f）。
- **卡片**：`--bg-card` 底 + 1rpx `--border` 边 + 阴影；选中态 `--bg-accent-soft` 底 + accent 边。
- **主按钮**：品牌渐变 + 反白 + 600 字重；次按钮：`--bg-subtle` 底 + --text-2。
- **输入栏（对话页）**：悬浮胶囊卡片——与页面边缘留 20rpx、圆角 32rpx、卡片底 + 边框 + 投影。
- **对话头部**：sticky + 半透明毛玻璃（浅色 rgba(255,255,255,.86) / 深色 rgba(20,22,28,.86)）+ blur(12px)。

## 5. 暗色规则

- 页面通过 `<html data-theme="dark">` 切换（utils/theme.js），组件内 scoped 样式可直接写 `[data-theme="dark"] .xxx` 覆盖。
- 语音通话页恒为深色设计，不随主题切换。
- 深色下禁用纯黑（#000）与大面积纯白；表格/引用块等富文本元素使用 `--bg-subtle` 底。

## 6. 禁止事项

- 禁止硬编码中性色值（灰阶文字/白底/灰底）——必须用令牌。
- 禁止在一页内混用两套圆角/阴影体系。
- 禁止强调渐变用于正文区域底色。
