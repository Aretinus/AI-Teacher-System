$$
{ \frac { d F } { d x } } - { \frac { d } { d x } } \left( y ^ { \prime } { \frac { \partial F } { \partial y ^ { \prime } } } \right) = { \frac { \partial F } { \partial x } } + y ^ { \prime } { \frac { \partial F } { \partial y } } - y ^ { \prime } { \frac { d } { d x } } \left( { \frac { \partial F } { \partial y ^ { \prime } } } \right)
$$

Rewriting the above equation to give

$$
{ \frac { d } { d x } } \left[ F - y ^ { \prime } { \frac { \partial F } { \partial y ^ { \prime } } } \right] - { \frac { \partial F } { \partial x } } = y ^ { \prime } \left[ { \frac { \partial F } { \partial y } } - { \frac { d } { d x } } \left( { \frac { \partial F } { \partial y ^ { \prime } } } \right) \right]
$$

By the Euler–Lagrange equation (3.32a) we see that the right-hand side of the above equation is zero. Thus,

$$
\frac { d } { d x } \left[ F - y ^ { \prime } \frac { \partial F } { \partial y ^ { \prime } } \right] - \frac { \partial F } { \partial x } = 0\tag{3.35}
$$

Equation (3.35) is another useful form of the Euler–Lagrange equation.

\## 3.6.3 Special cases

Case I. Often in applications, the functional F does not depend directly on x and the Euler– Lagrange equation, in this case, takes a particularly nice form. Here we have $\partial F / \partial x = 0$ and the corresponding form of Euler–Lagrange equation (3.35) becomes

$$
{ \frac { d } { d x } } \left[ F - y ^ { \prime } { \frac { \partial F } { \partial y ^ { \prime } } } \right] = 0
$$

Integrating, we get the first integral of Euler–Lagrange equation

$$
F - y ^ { \prime } { \frac { \partial F } { \partial y ^ { \prime } } } = C\tag{3.36}
$$

Thus, the extremizing function y is obtained as the solution of a first-order differential equation (3.36) involving y and $y ^ { \prime }$ only. This simplified form of Euler–Lagrange equation (3.36) is known as the Beltrami identity. The combination $F - y \prime F _ { y \prime }$ that appears on the left of the Beltrami identity is sometimes referred to as Hamiltonian.

Case II. If F is independent of y, then $\partial F / \partial y = 0$ and the form of Euler–Lagrange equation (3.32a) becomes

$$
{ \frac { d } { d x } } \left( { \frac { \partial F } { \partial y ^ { \prime } } } \right) = 0
$$

Integrating, we get the first integral of the Euler–Lagrange equation as,

$$
{ \frac { \partial F } { \partial y ^ { \prime } } } = k\tag{3.37}
$$

where k is a constant. Note that equation (3.37) is a first order differential equation involving x and $y ^ { \prime }$
