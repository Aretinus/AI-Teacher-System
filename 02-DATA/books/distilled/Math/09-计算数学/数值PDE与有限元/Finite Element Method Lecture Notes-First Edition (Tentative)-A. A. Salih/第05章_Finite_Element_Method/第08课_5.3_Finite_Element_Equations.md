\## 5.3 Finite Element Equations

Here we proceed to develop finite element equation for a one-dimensional problem using Galerkin method. Consider the differential equation of the form

$$
{ \frac { d ^ { 2 } y } { d x ^ { 2 } } } + Q ( x ) y = F ( x ) , \qquad x \in [ a , b ]\tag{5.1}
$$

The residual for the element (e) is obtained by substituting the approximate solution $\phi \left( x \right)$ for $y ( x )$ in the differential equation (5.1)

$$
R ^ { ( e ) } ( x ) = \frac { d ^ { 2 } \phi } { d x ^ { 2 } } + Q ( x ) \phi - F ( x ) \qquad x \in [ x _ { i } , x _ { j } ]\tag{5.13}
$$

where $\phi ( x )$ is the interpolation polynomial for the element (e) is given by

$$
{ \phi } ^ { ( e ) } ( x ) = N _ { i } { \phi } _ { i } + N _ { j } { \phi } _ { j } = [ { \mathsf { N } } ] [ { \phi } ^ { ( e ) } ]\tag{5.14}
$$

The Galerkin method sets the integral of residual $R ^ { ( e ) }$ weighted with each of the $N \varsigma$ (over the length of the element) to zero:

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { i } R ^ { ( e ) } ( x ) d x = 0\tag{5.15a}
$$

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { j } R ( x ) ^ { ( e ) } d x = 0\tag{5.15b}
$$

Substituting the residual from (5.13) into (5.15), we get the weighted residual equation for the element (e):




$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { i } \left( \frac { d ^ { 2 } \phi } { d x ^ { 2 } } + Q ( x ) \phi - F ( x ) \right) d x = 0\tag{5.16a}
$$

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { j } \left( { \frac { d ^ { 2 } \phi } { d x ^ { 2 } } } + Q ( x ) \phi - F ( x ) \right) d x = 0\tag{5.16b}
$$

which may be expanded as

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { i } \frac { d ^ { 2 } \phi } { d x ^ { 2 } } d x + \int _ { x _ { i } } ^ { x _ { j } } N _ { i } Q ( x ) \phi d x - \int _ { x _ { i } } ^ { x _ { j } } N _ { i } F ( x ) d x = 0\tag{5.17a}
$$

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { j } \frac { d ^ { 2 } \phi } { d x ^ { 2 } } d x + \int _ { x _ { i } } ^ { x _ { j } } N _ { j } Q ( x ) \phi d x - \int _ { x _ { i } } ^ { x _ { j } } N _ { j } F ( x ) d x = 0\tag{5.17b}
$$

The first integral in (5.17a) can be transformed by applying integration by $\mathsf { p a r t s } ^ { 1 }$ to yield

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { i } { \frac { d ^ { 2 } \phi } { d x ^ { 2 } } } d x = \left[ N _ { i } { \frac { d \phi } { d x } } \right] _ { x _ { i } } ^ { x _ { j } } - \int _ { x _ { i } } ^ { x _ { j } } { \frac { d N _ { i } } { d x } } { \frac { d \phi } { d x } } d x
$$

Thus, we have taken the significant step of lowering the second-order derivative in the formulation to a first-order derivative. Next, in the second integral, we will take $Q$ out from the integrand as ${ \overline { { Q } } } ,$ an average value within the element. We also take $F$ outside the third integral by defining the average value ${ \overline { { F } } } ;$

$$
\int _ { x _ { i } } ^ { x _ { j } } N _ { i } Q ( x ) \phi d x = \overline { { Q } } \int _ { x _ { i } } ^ { x _ { j } } N _ { i } \phi d x \qquad \mathrm { a n d } \qquad \int _ { x _ { i } } ^ { x _ { j } } N _ { i } F ( x ) d x = \overline { { F } } \int _ { x _ { i } } ^ { x _ { j } } N _ { i } d x
$$

With these results, equation (5.17a) becomes

$$
- \int _ { x _ { i } } ^ { x _ { j } } \frac { d N _ { i } } { d x } \frac { d \phi } { d x } d x + \overline { { Q } } \int _ { x _ { i } } ^ { x _ { j } } N _ { i } \phi d x - \overline { { F } } \int _ { x _ { i } } ^ { x _ { j } } N _ { i } d x + \left[ N _ { i } \frac { d \phi } { d x } \right] _ { x _ { i } } ^ { x _ { j } } = 0
$$

The last term of the above equation can be simplified as follows:

$$
\left[ N _ { i } \frac { d \phi } { d x } \right] _ { x _ { i } } ^ { x _ { j } } = \left. N _ { i } ( x _ { j } ) \frac { d \phi } { d x } \right| _ { x _ { j } } - \left. N _ { i } ( x _ { i } ) \frac { d \phi } { d x } \right| _ { x _ { i } }
$$

However, recall that $N _ { i } ( x _ { i } ) = 1$ and $N _ { i } ( x _ { j } ) = 0$ , and therefore

$$
\left[ N _ { i } { \frac { d \phi } { d x } } \right] _ { x _ { i } } ^ { x _ { j } } = - \left. { \frac { d \phi } { d x } } \right| _ { x _ { i } }
$$

With this simplification and after changing the sign, we have

$$
\int _ { x _ { i } } ^ { x _ { j } } { \frac { d N _ { i } } { d x } } { \frac { d \phi } { d x } } d x - { \overline { { Q } } } \int _ { x _ { i } } ^ { x _ { j } } N _ { i } \phi d x + { \overline { { F } } } \int _ { x _ { i } } ^ { x _ { j } } N _ { i } d x + \left. { \frac { d \phi } { d x } } \right| _ { x _ { i } } = 0\tag{5.18a}
$$




Doing the similar exercise with equation (5.17b) gives

$$
\int _ { x _ { i } } ^ { x _ { j } } \frac { d N _ { j } } { d x } \frac { d \phi } { d x } d x - \overline { { Q } } \int _ { x _ { i } } ^ { x _ { j } } N _ { j } \phi d x + \overline { { F } } \int _ { x _ { i } } ^ { x _ { j } } N _ { j } d x - \left. \frac { d \phi } { d x } \right| _ { x _ { j } } = 0\tag{5.18b}
$$

Notice that the integration by parts has led to two significant outcomes. First, it has incorporated the natural (or Neumann) boundary conditions:

$$
 { \frac { d \phi } { d x } } | _ { x _ { i } } \qquad { \mathrm { a n d } } \qquad { \frac { d \phi } { d x } } | _ { x _ { j } }
$$

directly into the element equations. Second, it has lowered the second derivative to a first derivative. This latter outcome yields the significant result that the approximation functions need to preserve continuity of $\phi ( x )$ but not slope $\left( d \phi / d x \right)$ at the nodes.

Combining the integral equations (5.18a) and (5.18b) to obtain

$$
\int _ { x _ { i } } ^ { x _ { j } } \frac { d [ \mathsf { N } ] ^ { T } } { d x } \frac { d \phi } { d x } d x - \overline { { Q } } \int _ { x _ { i } } ^ { x _ { j } } [ \mathsf { N } ] ^ { T } \phi d x + \overline { { F } } \int _ { x _ { i } } ^ { x _ { j } } [ \mathsf { N } ] ^ { T } d x - \left[ [ \mathsf { N } ] ^ { T } \frac { d \phi } { d x } \right] _ { x _ { i } } ^ { x _ { j } } = [ 0 ]\tag{5.19}
$$

where

$$
[ \mathsf { N } ] = \left[ \begin{array} { l l } { N _ { i } } & { N _ { j } } \end{array} \right]
$$

Next, the element interpolation polynomial

$$
\phi ^ { ( e ) } ( x ) = [ \mathsf { N } ] [ \phi ^ { ( e ) } ]
$$

can be substituted in the equation (5.19) to yield equation for element $( e )$ :

$$
\left( \int _ { x _ { i } } ^ { x _ { j } } \frac { d [ \mathsf { N } ] ^ { T } } { d x } \frac { d [ \mathsf { N } ] } { d x } d x - \overline { { Q } } \int _ { x _ { i } } ^ { x _ { j } } [ \mathsf { N } ] ^ { T } [ \mathsf { N } ] d x \right) [ \phi ^ { ( e ) } ] = - \overline { { F } } \int _ { x _ { i } } ^ { x _ { j } } [ \mathsf { N } ] ^ { T } d x + \left[ [ \mathsf { N } ] ^ { T } \frac { d \phi } { d x } \right] _ { x _ { i } } ^ { x _ { j } }\tag{5.20}
$$

where

$$
[ { \phi } ^ { ( e ) } ] = \left[ \begin{array} { l } { { \phi } _ { i } } \\ { { \phi } _ { j } } \end{array} \right]
$$

is the element nodal vector of unknowns. The equation (5.20) for the element (e) can be written in the following generic form:




$$
[ \mathsf { K } ^ { ( e ) } ] [ \phi ^ { ( e ) } ] = [ \mathsf { f } ^ { ( e ) } ] + [ \mathsf { I } ^ { ( e ) } ]\tag{5.21}
$$

where the square matrix $[ \mathsf { K } ^ { ( e ) } ]$ is the element stiffness matrix,

$$
[ \mathsf { K } ^ { ( e ) } ] = \int _ { x _ { i } } ^ { x _ { j } } \frac { d [ \mathsf { N } ] ^ { T } } { d x } \frac { d [ \mathsf { N } ] } { d x } d x - \overline { { Q } } \int _ { x _ { i } } ^ { x _ { j } } [ N ] ^ { T } \left[ \mathsf { N } \right] d x
$$

the vector $[ \mathsf { f } ^ { ( e ) } ]$ is the element force vector,

$$
[ { \sf f } ^ { ( e ) } ] = - \overline { { F } } \int _ { x _ { i } } ^ { x _ { j } } [ { \sf N } ] ^ { T } d x
$$

and the vector $[ | ^ { ( e ) } ]$ is the inter-element requirement

$$
[ \mathsf { I } ^ { ( e ) } ] = \left[ [ \mathsf { N } ] ^ { T } \frac { d \phi } { d x } \right] _ { x _ { i } } ^ { x _ { j } }
$$

When the element equations are assembled to get the global equation the inter-element requirement terms will cancel each other except for the boundary elements. For the boundary element the derivative type boundary conditions (natural boundary conditions in FEM terminology) are implemented using the inter-element requirement.

The next major exercise is the computation of integral involved in the element equation. For this, we can either use individual nodal equations (5.18a) and (5.18b) or the combined form of (5.20). $$

After the individual element equations are derived, they must be linked together or assembled to characterize the unified behavior of the entire system. The assembly process is governed by the concept of continuity. That is, the solutions for contiguous elements are matched so that the unknown values (and sometimes the derivatives) at their common nodes are equivalent. Thus, the total solution will be continuous. The global finite element equation will have the form

$$
[ \mathsf { K } ] [ \phi ] = [ \mathsf { f } ]\tag{5.25}
$$

where [K] is the global stiffness matrix and [f] is the global force vector.
