# 5.2 Two-dimensional Elements

So far we have discussed some of the one-dimensional elements which is suitable for one-dimensional problems governed by ordinary differential equations. For two-dimensional problem governed by PDE's requires the determination of dependent variable in two-dimensional domains. For the discretization of a two-dimensional space we use two-dimensional elements. Two basic types of two-dimensional elements are the linear triangular element and bilinear rectangular element. Despite the simplicity of these elements they are extensively used in finite element analysis of heat transfer and solid mechanics problems.
