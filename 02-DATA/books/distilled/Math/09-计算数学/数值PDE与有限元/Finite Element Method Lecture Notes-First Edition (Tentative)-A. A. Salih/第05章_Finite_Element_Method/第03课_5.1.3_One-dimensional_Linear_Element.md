To apply the finite element method, the first step is to discretize the domain. We use one-dimensional linear element for this purpose. A linear element is an element for which the assumed function varies linearly within the element. Since two points are needed to uniquely specify a linear function, a linear element should have exactly two nodes. The nodes of the elements are numbered from left to right. We cannot place the nodes arbitrarily. The are certain rules to be followed. These are:

1.. Place the nodes closer in the region where you expect the variables to change rapidly and further apart where the variable have less changes.
2. Place a node wherever a stepped or abrupt change in the material or geometric properties of the domain occurs.
3. Place a node wherever the numerical value of the unknown variable is desired.
