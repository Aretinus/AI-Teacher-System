# 浣溪沙 和柳亚子先生

浣溪沙 和柳亚子先生

一九五○年十月

一九五○年国庆观剧，柳亚子先生即席[1]赋浣溪沙，因步其

韵[2]奉和。

长夜难明赤县[3]天，百年魔怪舞翩跹[4]，人民五亿不团圆。一唱

雄鸡天下白[5]，万方[6]乐奏[7]有于阗[8]，诗人兴会更无前[9]。

这首词最早发表在《诗刊》一九五七年一月号。

附：柳亚子原词

浣溪沙

十月三日之夕于怀仁堂观西南各民族文工团、新疆文工团、吉林

省延边文工团、内蒙古文工团联合演出歌舞晚会，毛主席命填是阕，

用纪大团结之盛况云尔！

火树银花[10]不夜天。弟兄姊妹舞翩跹[11]。歌声唱彻月儿圆。

（原注）不是一人能领导[12]，那容百族共骈阗[13]？良宵盛会喜空前

[14]！

【原注】新疆哈萨克族民间歌舞有《圆月》一歌云。
